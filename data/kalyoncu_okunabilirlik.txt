M. Rahman Kalyoncu tarafından 2025 yılında Ondokuz Mayıs Üniversitesi'nde sunulan **"Türkçe İçin Yeni Bir Okunabilirlik Formülü"** başlıklı yüksek lisans tezinde, Türkçenin yapısına uygun 4 farklı çoklu regresyon denklemi önerilmiştir.

Tezde geliştirilen formüller; metindeki hece/cümle uzunluğu gibi mekanik nicel değişkenlerin yanı sıra, toplum genelinin ve 5. sınıf öğrencilerinin bildiği kabul edilen **4.600 sözcüklük bilinirlik temelli kelime listesini (KL)** ve **sözcük çeşitliliğini (TTR)** dikkate almaktadır.

---

## Tezde Önerilen Formüller ve Sınıf Seviye Aralıkları

### 1. Formül Değişkenleri

* **KL (Kelime Listesi Puanı):** Metinde, 4.600 sözcüklük bilinirlik listesinde yer almayan sözcüklerin oranı ($\frac{\text{Listede Olmayan Sözcük Sayısı}}{\text{Toplam Sözcük Sayısı}} \times 100$).


* **TTR (Type-Token Ratio / Sözcük Çeşitliliği):** Metinde yalnızca bir kez geçen gövde sözcüklerin oranı ($\frac{\text{Bir Kez Geçen Sözcük Sayısı}}{\text{Toplam Sözcük Sayısı}} \times 100$).


* **OCU (Ortalama Cümle Uzunluğu):** $\frac{\text{Toplam Sözcük Sayısı}}{\text{Toplam Cümle Sayısı}}$.


* **KCO (Kompleks Cümle Oranı):** Basit olmayan (içinde yan cümle, fiilimsi veya bağlaç barındıran) cümlelerin oranı ($\frac{\text{Basit Olmayan Cümle Sayısı}}{\text{Toplam Cümle Sayısı}} \times 100$).


* **YCO (Yan Cümle Oranı):** $\frac{\text{Toplam Fiilimsi Sayısı}}{\text{Toplam Cümle Sayısı}} \times 10$.



---

### 2. Formüller ($R^2$ Başarı Oranları)

1. **1. Formül (En Kapsamlı - $R^2 = 0.99$)**:



$$\text{Metin Zorluğu} = -29.829 + 0.508 \times \text{KL} + 1.191 \times \text{TTR} + 0.733 \times \text{KCO} - 0.66 \times \text{OCU}$$


2. **2. Formül ($R^2 = 0.82$)**:



$$\text{Metin Zorluğu} = 25.457 + 0.877 \times \text{KL} + 0.668 \times \text{TTR} + 0.333 \times \text{OCU}$$


3. **3. Formül ($R^2 = 0.83$)**:



$$\text{Metin Zorluğu} = 25.153 + 0.834 \times \text{KL} + 0.686 \times \text{TTR} + 0.226 \times \text{YCO}$$


4. **4. Formül (En Pratik / Kolay - $R^2 = 0.78$)**:



$$\text{Metin Zorluğu} = 43.368 + 1.008 \times \text{KL} + 0.624 \times \text{OCU}$$

## Python Okunabilirlik Ölçüm Betiği

Aşağıdaki Python kodu metinlerin parametrelerini hesaplayıp tezde belirtilen 4 formüle göre okunabilirlik seviyelerini çıktı olarak üretir.

```python
import re
from collections import Counter

class KalyoncuOkunabilirlik:
    def __init__(self, kelime_listesi=None):
        """
        :param kelime_listesi: Tezdeki 4600 kelimelik bilinirlik temelli kelime listesi (set veya list).
        Eğer verilmezse varsayılan temel bir Türkçe kelime kümesi simüle edilir.
        """
        # Tezde belirtilen 4600 kelimelik kelime listesi
        self.kelime_listesi = set(kelime_listesi) if kelime_listesi else self._varsayilan_kelime_listesi()
        
        # Türkçe fiilimsi ekleri (Yaklaşık tespit için regex)
        self.fiilimsi_pattern = re.compile(
            r'\b\w+(?:an|en|asıl|esil|maz|mez|ar|er|ır|ir|dık|dik|duk|dük|acak|ecek|mış|miş|muş|müş|'
            r'ıp|ip|up|üp|arak|erek|madan|meden|maksızın|meksizin|ınca|ince|dıkça|dikçe|'
            r'ma|me|ış|iş|uş|üş|mak|mek)\b', 
            re.IGNORECASE
        )
        
        # Bağlaçlar ve yan cümle göstergeleri
        self.baglaclar = {"ve", "veya", "yahut", "ki", "de", "da", "ama", "fakat", "lakin", "ancak", "çünkü", "oysa", "ise"}

    def _varsayilan_kelime_listesi(self):
        """Örnek çalıştırma için temel kelime kümesi örneği."""
        return {
            "bir", "bu", "şu", "o", "ve", "de", "da", "ile", "için", "ne", "her", "kendi",
            "gibi", "kadar", "daha", "çok", "en", "var", "yok", "gelmek", "gitmek", "almak",
            "vermek", "olmak", "etmek", "yapmak", "bakmak", "görmek", "demek", "bilmek",
            "ev", "su", "gün", "insan", "çocuk", "zaman", "göz", "el", "yol", "yer", "yıl"
        }

    def metni_temizle_ve_cumlelere_ayir(self, metin):
        """Metni cümlelere ve kelimelere böler."""
        # Noktalama işaretlerine göre cümle ayrımı
        raw_cumleler = re.split(r'[.!?]+', metin)
        cumleler = [c.strip() for c in raw_cumleler if c.strip()]
        
        # Kelimeleri ayıklama
        kelimeler = re.findall(r'\b[a-zA-CçĞğıİöŞşÜü]+\b', metin.lower())
        
        return cumleler, kelimeler

    def degiskenleri_hesapla(self, metin):
        """Tezde yer alan temel metin değişkenlerini hesaplar."""
        cumleler, kelimeler = self.metni_temizle_ve_cumlelere_ayir(metin)
        
        toplam_cumle = max(len(cumleler), 1)
        toplam_kelime = max(len(kelimeler), 1)
        
        # 1. OCU: Ortalama Cümle Uzunluğu
        ocu = toplam_kelime / toplam_cumle
        
        # 2. KL: Kelime Listesinde Olmayan Sözcük Oranı (%)
        listede_olmayan = sum(1 for k in kelimeler if k not in self.kelime_listesi)
        kl = (listede_olmayan / toplam_kelime) * 100
        
        # 3. TTR: Tekrarlanmayan (Bir kez geçen) Kelime Oranı (%)
        kelime_sayilari = Counter(kelimeler)
        bir_kez_gecen = sum(1 for k, count in kelime_sayilari.items() if count == 1)
        ttr = (bir_kez_gecen / toplam_kelime) * 100
        
        # 4. KCO: Kompleks Cümle Oranı (%)
        # İçinde fiilimsi, bağlaç veya birden fazla yargı geçen cümleler
        kompleks_cumle_sayisi = 0
        fiilimsi_toplami = 0
        
        for cumle in cumleler:
            fiilimsiler = self.fiilimsi_pattern.findall(cumle)
            fiilimsi_toplami += len(fiilimsiler)
            cumle_kelimeleri = set(re.findall(r'\b\w+\b', cumle.lower()))
            
            # Cümlede bağlaç veya fiilimsi var mı?
            has_baglac = bool(cumle_kelimeleri.intersection(self.baglaclar))
            if len(fiilimsiler) > 0 or has_baglac or len(cumle_kelimeleri) > 10:
                kompleks_cumle_sayisi += 1
                
        kco = (kompleks_cumle_sayisi / toplam_cumle) * 100
        
        # 5. YCO: Yan Cümle Oranı
        yco = (fiilimsi_toplami / toplam_cumle) * 10
        
        return {
            "OCU": ocu,
            "KL": kl,
            "TTR": ttr,
            "KCO": kco,
            "YCO": yco,
            "Toplam_Cumle": toplam_cumle,
            "Toplam_Kelime": toplam_kelime
        }

    def seviye_belirle(self, skor, formul_no=1):
        """Hesaplanan zorluk skorunu tezdeki seviye aralıklarına eşler."""
        if formul_no == 1:
            if skor < 30: return "3. Sınıf Öncesi"
            elif skor <= 40: return "3 ve 4. Sınıf"
            elif skor <= 50: return "5 ve 6. Sınıf"
            elif skor <= 60: return "7 ve 8. Sınıf"
            elif skor <= 70: return "9 ve 10. Sınıf"
            elif skor <= 76: return "11 ve 12. Sınıf"
            elif skor <= 85: return "Lisans"
            else: return "Lisansüstü"
            
        elif formul_no in (2, 3):
            if skor < 35: return "3. Sınıf Öncesi"
            elif skor <= 45: return "3 ve 4. Sınıf"
            elif skor <= 55: return "5 ve 6. Sınıf"
            elif skor <= 60: return "7 ve 8. Sınıf"
            elif skor <= 64 if formul_no == 2 else skor <= 65: return "9 ve 10. Sınıf"
            elif skor <= 70: return "11 ve 12. Sınıf"
            elif skor <= 85: return "Lisans"
            else: return "Lisansüstü"
            
        elif formul_no == 4:
            if skor < 40: return "3. Sınıf Öncesi"
            elif skor <= 50: return "3 ve 4. Sınıf"
            elif skor <= 55: return "5 ve 6. Sınıf"
            elif skor <= 59: return "7 ve 8. Sınıf"
            elif skor <= 65: return "9 ve 10. Sınıf"
            elif skor <= 72: return "11 ve 12. Sınıf"
            elif skor <= 85: return "Lisans"
            else: return "Lisansüstü"

    def hesapla(self, metin):
        """Tüm formüllere göre okunabilirlik skorlarını ve seviyelerini döndürür."""
        v = self.degiskenleri_hesapla(metin)
        
        # Tez Formülleri
        f1_skor = -29.829 + (0.508 * v["KL"]) + (1.191 * v["TTR"]) + (0.733 * v["KCO"]) - (0.66 * v["OCU"])
        f2_skor = 25.457 + (0.877 * v["KL"]) + (0.668 * v["TTR"]) + (0.333 * v["OCU"])
        f3_skor = 25.153 + (0.834 * v["KL"]) + (0.686 * v["TTR"]) + (0.226 * v["YCO"])
        f4_skor = 43.368 + (1.008 * v["KL"]) + (0.624 * v["OCU"])
        
        return {
            "Degiskenler": v,
            "Formul_1": {"Skor": round(f1_skor, 2), "Seviye": self.seviye_belirle(f1_skor, 1)},
            "Formul_2": {"Skor": round(f2_skor, 2), "Seviye": self.seviye_belirle(f2_skor, 2)},
            "Formul_3": {"Skor": round(f3_skor, 2), "Seviye": self.seviye_belirle(f3_skor, 3)},
            "Formul_4": {"Skor": round(f4_skor, 2), "Seviye": self.seviye_belirle(f4_skor, 4)},
        }


# --- Kullanım Örneği ---

    # 4600 kelimelik listeyi txt veya json dosyasından yükleyebilirsiniz:

    olcer = KalyoncuOkunabilirlik()
    sonuclar = olcer.hesapla(ornek_metin)
    
    print("--- METİN DEĞİŞKENLERİ ---")
    for k, val in sonuclar["Degiskenler"].items():
        print(f"{k}: {round(val, 2) if isinstance(val, float) else val}")
        
    print("\n--- OKUNABİLİRLİK HESAPLAMA SONUÇLARI ---")
    print(f"1. Formül (En Kapsamlı R²=0.99) : Skor = {sonuclar['Formul_1']['Skor']} --> {sonuclar['Formul_1']['Seviye']}")
    print(f"2. Formül (R²=0.82)              : Skor = {sonuclar['Formul_2']['Skor']} --> {sonuclar['Formul_2']['Seviye']}")
    print(f"3. Formül (R²=0.83)              : Skor = {sonuclar['Formul_3']['Skor']} --> {sonuclar['Formul_3']['Seviye']}")
    print(f"4. Formül (En Pratik R²=0.78)   : Skor = {sonuclar['Formul_4']['Skor']} --> {sonuclar['Formul_4']['Seviye']}")
```
